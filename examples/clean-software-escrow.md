# Software Escrow Agreement — Balanced Terms

**Depositor:** Vertex Systems, Inc. ("Depositor")
**Beneficiary:** Initech LLC ("Beneficiary")
**Escrow Agent:** Iron Mountain Escrow Services ("Escrow Agent")
**Effective Date:** April 15, 2026

## 1. Deposits

Depositor shall deposit each generally available release, update, and patch within thirty (30) days of its release to Beneficiary. Each deposit includes build instructions, environment specifications, third-party dependency details, and a named technical contact available for release support.

## 2. Verification

Escrow Agent shall technically verify each deposit for completeness and buildability within thirty (30) days of deposit and annually thereafter, at Depositor's expense.

## 3. Release Events

Release events include: (a) Depositor's insolvency; (b) Depositor's failure to provide support for ninety (90) days; (c) discontinuation of the Software; (d) change of control of Depositor; (e) Depositor's uncured material breach.

## 4. Release Disputes

Depositor may object within fifteen (15) days; unresolved objections go to expedited arbitration, and Escrow Agent releases on the arbitrator's order.

## 5. Post-Release Support

Following release, Depositor provides ninety (90) days of technical support for the released materials at pre-release rates.

## 6. Fees

Escrow fees are shared equally; Depositor pays setup and annual fees, Beneficiary pays only fees arising from a release event.

## 7. Escrow Agent Liability

The liability cap does not apply to loss of or damage to deposited materials caused by Escrow Agent's negligence.
