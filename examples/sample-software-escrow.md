# Software Escrow Agreement — Vertex Systems Source Code Escrow

**Depositor:** Vertex Systems, Inc. ("Depositor")
**Beneficiary:** Initech LLC ("Beneficiary")
**Escrow Agent:** Iron Mountain Escrow Services ("Escrow Agent")
**Effective Date:** April 15, 2026

## 1. Deposits

Depositor shall deposit the initial version of the Software source code within thirty (30) days of the Effective Date.

## 2. Release Events

Escrow Agent shall release the deposited materials to Beneficiary solely upon Depositor's bankruptcy, insolvency, or assignment for the benefit of creditors.

## 3. Objections

Depositor may object to any release request by written notice to Escrow Agent. Upon objection, Escrow Agent shall withhold release pending resolution of the dispute between the parties.

## 4. Fees

Beneficiary shall pay all escrow fees, including setup fees, annual fees, and any verification fees.

## 5. Verification

Escrow Agent accepts deposits as-is and has no duty to verify the completeness or accuracy of deposited materials.

## 6. Liability of Escrow Agent

Escrow Agent's total liability under this Agreement shall not exceed the fees paid by Beneficiary in the twelve (12) months preceding the claim.

## 7. Term

This Agreement continues until terminated by either party on ninety (90) days' notice.
